# Proyecto_DeepLearning
Proyecto de Fundamentos de Deep Learning sobre recaudo publico de impuestos, utilizando modelos de redes neuronales recurrentes, perceptrones multicapa y redes LSTM, con el objetivo de predecir la variable recaudo. 
Se utilizan notebooks de Python para el desarrollo del proyecto de investigación.
Se cuenta con un dataset de 44682 registros con dos columnas: 'Fecha_Hora'	y 'Valor Pago', que representan el momento con registro de 'año-mes-dia hora' en los que se registró el valor de pago de forma agrupada, mediante pago web.

# Arquitectura propuesta para los modelos de predicción de recaudo:
La tarea asignada para cada red es regresión. Se eligen 3 modelos RNN, LSTM y GRU, con un look_back de 10 constante para todos los modelos, un dropout variable, pero recomendado de 0.3 para evitar el sobre ajuste. Cada modelo cuenta con 3 capas y con un número variable de unidades en cada capa, excepto en la capa de salida la cual es una unidad.

# Métricas
Las métricas de desempeño utilizadas para evaluar los modelos de aprendizaje profundo y redes neuronales son las siguientes: RMSE, MAPE, MAE, sMAPE, MASE y R², todas estas métricas ofrecen visiones complementarias del error, en este caso el MAPE (promedio del error absoluto) muestra la precisión relativa en porcentaje, lo que facilita comparar resultados, mientras que el RMSE (raíz cuadrada del promedio de los errores al cuadrado) mide la magnitud absoluta de los errores en las mismas unidades de la variable, penalizando con más fuerza los fallos grandes. El MAE (error absoluto medio) refleja el error promedio en términos absolutos y es más robusto ante valores atípicos, el sMAPE (error porcentual absoluto medio simétrico) ajusta el MAPE para evitar distorsiones cuando los valores reales son cercanos a cero, y el MASE (error absoluto escalado medio) permite comparar el desempeño del modelo frente a un modelo de referencia, lo que resulta útil para validar mejoras. Finalmente, el R² (coeficiente de determinación) indica la proporción de la variabilidad de los datos explicada por el modelo, siendo una métrica de ajuste global.
